## 2.4 Project: Application Flow Control

# Criteria
- The application's first outputted line should be the application's name in the form of "<Your Student ID> Spreadsheet Automation Menu."
- Instead of using single-line print statements for your menu, add the possible menu options to a list, dictionary, or tuple.
- Use a for-loop to loop through menu options and print them to the console.
- Using if-else statements, or a similar construct, determine if the user input corresponds to a valid menu option.
- If the choice is invalid, print the following: "Error: Invalid choice selected."
- If the choice was valid, print the selected option number and the current date and time.
